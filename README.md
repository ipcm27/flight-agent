Welcome to **the most over-engineered 2-agent travel assistant you’ll ever see**.

## 🎯 What is this?

A small test project where I:

* Used OpenAI’s Agent SDK
* Created a classifier agent
* Created a flight agent
* Created an itinerary agent
* Logged everything like NASA was monitoring it
* Automatically generated HTML widgets
* Automatically opened the widgets in the browser
* And pretended this was all part of the plan

Basically, it’s a travel assistant that **does not book flights**,
**does not guarantee accuracy**,
but **does print very pretty cards**.

## 🔧 What it does

* 🧠 Classifies your message as **flight info** or **itinerary**
* ✈️ If it's flight info → generates a beautiful blue widget with times and cities
* 🗺️ If it's itinerary → generates a clean itinerary card
* 🌐 Opens the result automatically in your browser
* 🔥 Logs everything like it’s debugging the ISS
* 🎨 All styling done in raw HTML/CSS because suffering builds character

## 💻 How to run it

```bash
python main.py
```

Then type:

